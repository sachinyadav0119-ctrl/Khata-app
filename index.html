🎙️ Voice Assistant
Ask Khaata, add entries, or navigate — hands-free
Enable voice system
Turns the mic button on or off everywhere in the app. Off = mic button hidden, nothing listens.
Recognition language
Which language the microphone listens for.
Continuous conversation mode
Mic auto-reopens after each command for ~18s so you can correct or continue without re-tapping. Always exitable instantly.
🔒 Voice processing happens entirely in your browser using its built-in speech recognition (Web Speech API). No financial data or audio is sent to Anthropic, Khaata, or any external server by this feature. You can revoke microphone access any time in your browser's site settings. The mic never stays on in the background — it stops the moment a command session ends or times out.
